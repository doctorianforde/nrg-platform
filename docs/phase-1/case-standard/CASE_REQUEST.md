ERROR-PREVENTION ADDENDUM — apply to every question before finalizing:

1\. DISTRACTOR PLAUSIBILITY: Every distractor must be something a

competent entry-level nurse could genuinely consider in this

situation. Reject any option that is obviously wrong, absurd, or

unrelated to the case's clinical reality. Wrong answers must fail

because of a subtle reasoning error (wrong priority, wrong construct,

wrong timing, unsafe shortcut), never because they are silly.

2\. NO TELEGRAPHING: Do not place two cues of the same priority

category side by side. Spread cues across disclosure stages so the

answer at each stage is not pre-assembled. Do not give laboratory

reference ranges unless the educational objective specifically tests

range recall — students must interpret raw values using standard

entry-level knowledge, and the rationale must name that knowledge.

3\. FLUID BALANCE & ELECTROLYTES: For any case involving renal function,

dehydration, cardiac medication, electrolyte-active drugs (e.g.,

lithium, digoxin, diuretics), or IV therapy, include urine output

and/or serum electrolyte data at a clinically appropriate stage,

presented raw without flags, and use them either as evaluation data

(Q6) or as plausible distractors (Q2).

4\. SCOPE ASSUMPTIONS: If the keyed action depends on a standing order,

protocol, or scope rule, state that authority in the stem. The answer

must never rely on an unwritten local custom.

5\. SELF-TEST BEFORE OUTPUT: For each question, state in one sentence

why the best distractor is wrong. If you cannot write that sentence

without using the words "obviously" or "clearly," rewrite the

distractor.
